# 🚀 Learning Path Generator AI Agent

This project is an AI-powered Learning Path Generator built using n8n. It automates the process of creating structured, day-wise learning plans based on a user's goal.

## 🔹 Features

* Generates personalized learning paths from user input
* Uses AI (Google Gemini) for intelligent planning
* Fetches relevant learning resources using SerpAPI
* Automatically creates and updates Google Docs
* Schedules learning sessions in Google Calendar

## 🔹 Tech Stack

* n8n (Workflow Automation)
* Google Gemini API
* SerpAPI
* Google Docs API
* Google Calendar API

## 🔹 How It Works

1. User provides a learning goal
2. AI agent generates a structured roadmap
3. SerpAPI fetches useful resources
4. Google Docs stores the complete plan
5. Google Calendar schedules daily tasks

## 🔹 Outcome

This project transforms manual course planning into a fully automated, intelligent system, improving productivity and learning efficiency.
